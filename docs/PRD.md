# FileFit MVP 제품 요구사항

작성: 2026-10-23. 한국어 사용자가 제출 전 이미지·PDF의 규격을 맞추는 무료 웹 도구. 주요 유입 경로는 도구별 검색 결과와 가이드이며, 장기 수익 모델은 AdSense 광고다. 현 버전에는 광고·분석·AI API·로그인·DB·결제·업로드 서버가 없다.

## 사용자와 과업

- 지원서 사진의 픽셀·형식·최대 바이트를 동시에 맞춘다.
- JPG/PNG/WebP를 변환하거나 이미지의 용량을 줄인다.
- 여러 이미지를 A4 PDF로 묶고 PDF를 합치거나 지정 페이지를 추출한다.
- 결과를 직접 내려받고 설정 링크를 다시 사용한다.

## 범위와 결정

각 도구는 고유 정적 URL을 갖는다. 개인별 고유 URL 요구는 계정 없는 무작위 ID 포함 설정 URL 해시로 해석했다. 링크는 파일을 저장하거나 식별하지 않으며 다른 기기에서 설정만 복원한다. 파일 자체의 공유·동기화는 범위 밖이다.

이미지 규격 기본값은 300×400px / JPG / 100KB(100,000바이트). 여백 또는 중앙 자르기를 명시적으로 선택한다. 압축 및 형식 변환도 같은 규격 엔진을 사용하므로 원본 크기 유지를 원하면 원본 픽셀을 입력한다. 목표 바이트 이하의 실제 Blob을 찾은 경우에만 성공 처리한다. 실패 시 설정을 바꾸는 방법을 안내한다. 품질 탐색은 21단계로, 모든 가능한 인코더 설정의 수학적 불가능성을 증명하는 것은 아니다.

PDF 분할은 지정한 페이지를 하나의 새 PDF로 추출한다. 페이지별 ZIP 다운로드, OCR, 편집, 비밀번호 해제, 서명·양식 보존은 제외한다. PDF의 임베디드 정보나 개인정보를 제거하는 서비스가 아니다.

## 제한

파일당 20MiB, 합계 50MiB, 최대 20개. 원본·결과 이미지 16MP, 출력 한 변 8,000px 이하. PDF당 및 결과 200페이지 이하. 제한 내에서도 메모리 부족은 가능하다. 애니메이션 이미지는 첫 프레임만 처리한다.

## 출시 게이트

타입·린트·단위 테스트·브라우저 테스트·정적 빌드 성공. 실제 도메인/운영자/문의/호스팅 보관 정책 확정. 개인정보·약관을 실제 운영 내용에 맞게 검토. 실제 iOS/Android 및 Safari/Firefox 확인. AdSense 승인을 보장하거나 현재 광고 수익이 발생한다고 주장하지 않는다.

## 이후 측정

추후 별도 동의·정책 검토 후 Search Console의 검색 노출/클릭/인덱스 상태부터 확인한다. 파일명·파일 내용·문서 메타데이터는 분석 이벤트로 수집하지 않는다. 광고는 도구 조작과 다운로드 영역을 방해하지 않는 가이드 하단 영역부터 검토한다.
